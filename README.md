\# Student Grade Management System



A Java desktop application developed using Java Swing that allows users to manage student marks, calculate averages, assign grades, and view class statistics.



\## Features

\- Add students with their names and three assessment marks.

\- Validate student names and ensure marks are between 0 and 100.

\- Automatically calculate each student's average and assign a grade.

\- Display student results in a table.

\- Remove selected students from the table.

\- View the total number of students and the overall class average.

\- Clear input fields when adding another student.



\## Grading System

\- \*\*A:\*\* 80–100

\- \*\*B:\*\* 70–79

\- \*\*C:\*\* 60–69

\- \*\*D:\*\* 50–59

\- \*\*F:\*\* Below 50



\## Technologies Used

\- Java

\- Java Swing

\- AWT (Abstract Window Toolkit)

\- Apache NetBeans IDE



\## How to Run

1\. Clone or download this repository.

2\. Open Apache NetBeans.

3\. Select \*\*File → Open Project\*\* and choose the project folder.

4\. Run the `StudentGradeManager.java` application.
